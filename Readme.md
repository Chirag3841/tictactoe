Ultimate Tic Tac Toe
Features ✨
Stunning Visual Design: Neon-themed UI with smooth animations

Two Game Modes: Player vs Player and Player vs AI

Interactive Elements: Hover effects, sound feedback, and visual cues

Score Tracking: Keep track of wins for both players

Responsive Design: Works on desktop, tablet, and mobile devices

Sound Effects: Optional sound feedback for moves and game outcomes

Celebration Effects: Confetti animation when a player wins
How to Play 🎮
Choose your game mode (Player vs Player or Player vs AI)

Players take turns clicking on empty cells

Player X uses ❌ and Player O uses ⭕

First to get 3 in a row (horizontally, vertically, or diagonally) wins!

Click "Reset Game" to clear the board or "New Game" to reset scores
